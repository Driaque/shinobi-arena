# Fabled Rivals v0.39.0

## Painted fighters and arenas

- All ten original fighters now have detailed painted selection portraits that preserve their distinct outfits and identities.
- The five existing arenas have painted PNG previews and matching battle backgrounds: Skyglass Terrace, Frostbound Pass, Ember Forge, Moonlit Grove, and Sunken Court.
- Selection portraits use responsive PNG sizes instead of being reduced into tiny animated canvases. Stage previews load small images; full scenery loads only when a stage is rendered.

## Controls and compatibility

- Character selection, stage selection, touch, keyboard and controller controls work as before. Combat layout, stage IDs, physics and match results are unchanged.
- Canvas and PixiJS both support the scenery. Existing artwork remains available as a fallback while images load or when they fail.
- Native HTML portraits retain accessible radio labels and selected-player indicators. Reduced-motion users receive still artwork.

## Limits

- This update improves selection artwork and scenery. Existing fighter animation models remain in use during battles.
- Scenery is flattened painted artwork with existing effects, not separate parallax layers. A painted object does not add collision geometry.

## Delivery

- Production updates deploy only to the existing Render service. GitHub Pages publishing is retired.
