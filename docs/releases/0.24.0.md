# Fabled Rivals v0.24.0

## Playable PixiJS Visual Lab

- Open Visual Lab below the main game, or visit /visual-lab.html. This optional page adds PixiJS 8.22.0 with WebGL, original concept fighter Aren, a 16-pose sprite atlas and the detailed Skyglass Terrace arena. Both the PixiJS and Canvas comparison paths use the same artwork, camera and local combat state.
- Watch a real five-hit aerial route, awakening, double jump and air dash in the guided showcase. Controls switch to free practice. A/D or analog move horizontally; Z/L or analog up/down change depth; W jumps twice; Q/E dash; J/K attack; U launches; I/O use aerial techniques; H guards; S crouches; G charges and T awakens. Pull sideways twice to dash. Controls sit below the battlefield. Optional sound effects activate through a user gesture.
- Practice starts with awakening ready and refills health, chakra and stamina. The mirror opponent is a sparring echo of the same original visual fighter. Aren uses existing sword training rules as a visual stand-in, not a new ranked roster entry.

## Compare on your device

- Switch renderers without resetting the fight. Compare runs warm up each renderer, then play the same 300 simulation ticks at 60 Hz. Inspect frame p95, CPU render submission p95 and sample counts, or download local JSON measurements. Input-to-render submission and approximate JS heap readings appear where supported.
- CPU submission is not GPU completion or physical screen latency. Memory readings cover available JS heap, not total GPU/browser memory. Software WebGL in automated tests does not establish a physical iPhone performance improvement. No universal speedup or production-wide renderer migration is claimed.
- Resolution is capped by device pixel ratio and the selected limit. Both paths preserve sprite proportions. Reduced motion removes ambient motes and parallax. Missing WebGL or a lost graphics context falls back to Canvas; missing artwork shows a recoverable error and Back to game remains available.

## Compatibility

- The main game's Canvas renderer, controls, multiplayer protocol 6 and duel-0.20.0 rules remain unchanged. Profiles, loadouts, rankings, tournaments and archived replays remain compatible. The lab makes no arena API requests and does not submit results or alter online statistics.
- PixiJS and artwork load only on the Visual Lab page. Dedicated-domain hosting, a fully original competitive roster, production skeletal animation and migration of online fight rendering remain future work.
