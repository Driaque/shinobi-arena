# Fabled Rivals v0.34.1

## Character identity and naming

- Silent, Winta and Dora are consistently presented as original Fabled Rivals characters in roster data, help and documentation. Silent and Winta remain blood brothers.
- Silent’s defensive bloodline is Skyforged Aegis. Winta’s lightning bloodline is Stormheart, and his dash strike is Rimeflash.
- Frostmere is the brothers’ northern home in the Skyglass setting. Ability identifiers, HUD labels, icons and documentation use the updated names.

## Controls and compatibility

- Inputs, damage, timings, guard reflect, lightning amplification and awakenings are unchanged. Desktop, mobile, local and online modes use the same updated ability catalog.
- Character and equipment IDs are unchanged. Older saved builds containing renamed abilities need to be selected and saved again; incompatible saved loadouts fall back to the character’s default kit.

## Limits

- This update changes character naming and presentation; it adds no combat mechanics or new artwork. Optional guest fighters remain a separate roster classification.
