# Fabled Rivals v0.38.0

## Controller menu cursor

Move the right analog stick in setup screens, pause screens or open menus to show a cursor. Cross/A selects the highlighted control. Buttons, fighter-card labels, links and checkboxes activate directly; selects open an on-screen list navigable by cursor or D-pad. Select a position on a slider to change its value. Push the cursor toward the top or bottom edge of a scrollable panel to scroll it. D-pad/left-stick focus navigation remains available; using it hides the cursor. Circle/B closes an open cursor option list before backing out of its containing menu.

Settings → Feel → Controller menu cursor speed saves pointer speed on this device. Small stick deflections allow fine positioning and larger deflections move faster.

The cursor is disabled during active combat, where the right stick still aims compatible abilities. It hides when combat resumes, the controller disconnects, the browser loses focus, or the player uses touch, mouse or keyboard. Online matches continue while menus are open. Text entry still requires the device keyboard. This is an in-game cursor; browser chrome, external pages and system dialogs are outside its scope. Physical-controller and mobile hardware verification remains separate from automated tests.
