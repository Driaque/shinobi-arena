# Fabled Rivals v0.29.2

- Original continuous Canvas fighter animation is the default again. PixiJS still renders the battlefield and combat effects.
- Aren receives a layered courier outfit, scarf, ledger pouch, bracers, boots and a distinct swept-hair profile. Silent receives segmented steel armor, silver hair, a fitted mask, an ice crest and sheathed blades. Both designs follow the continuous combat pose.
- Graphics settings now offer Continuous and Painted fighter styles independently of the PixiJS/Canvas battlefield renderer. Choices persist between visits.
- Local movement uses bounded cosmetic projection between simulation ticks to improve high-refresh display cadence without buffering local input. Teleports, resets and missed simulation steps snap rather than projecting large displacements.
- PixiJS retains static scenery geometry and skips scene event traversal. Battlefield sizing uses resize notifications instead of a layout read on each draw.

## Controls and compatibility

Open Graphics, then Fighter animation to compare styles. Movement and attack controls, combat rules, online snapshot interpolation and replay samples are unchanged. WebGL loss continues to use Canvas fallback.

## Limits

Continuous fighters use the original procedural Canvas artwork. Painted fighters still have sparse key poses, including a two-pose run cycle. This update does not turn those sheets into full animation rigs. Local cosmetic projection is limited to one simulation tick and can correct at the next collision update.
