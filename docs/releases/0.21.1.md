# Shinobi Arena v0.21.1

## Character benchmark score correction

- Tournament scorelines and damage totals are attributed by player identity, including when socket arrival seats players in a different order from the stored pairing. Match winners were already credited by identity.
- Benchmark matches now enforce their scheduled starting sides, regardless of connection order. Existing completed pilot scorelines are corrected from immutable server match records when the server recovers the paused league. Saved fights and replays remain intact. The remaining league starting sides are balanced around completed battles, preserving three or four starts per side for this pilot.
- Live interruption reopens unfinished benchmark pairings. The operator resumes the existing event after this fix; completed matches are retained. The pilot remains a provisional fixed-loadout AI comparison.

## Compatibility

- Combat controls, protocol 6 and duel-0.20.0 rules are unchanged. Refresh for v0.21.1. Player Elo/rewards remain separate from benchmark results; ordinary tournament rewards and progression are unchanged. Existing replay retention and database limits still apply.
