# Fabled Rivals v0.27.0

## Every mode shares the battlefield

- PixiJS is now the default scenery/effects backend for CPU, local, Training, online battles, live spectating and archived replays. Graphics → Renderer selects PixiJS or Canvas compatibility. Missing WebGL/context loss falls back to Canvas; failed modules/art restore the original Canvas battlefield. Retry graphics rebuilds affected views. Closing the viewer releases its GPU resources.
- Skyglass Terrace gains perspective floor seams, subtle lane guides, foreground stone supports, lanterns and ground shimmer. Elemental fields, impact rings and projectile visuals share the same snapshot/camera. Bombs, kunai, marked kunai, shuriken and elemental projectiles have distinct geometry and colors. Reduced motion removes animated decorations; decorative-effects preferences remain respected. Scenery is visual: no new platforms, collision walls or terrain bonuses.
- Selected characters retain their own appearance; Aren uses the existing atlas. Other fighter bodies, weapon/status/item cues and text retain Canvas compatibility rendering. This is not a complete sprite/rig replacement for every fighter. The optional Practice mirror appearance is separate; its preference resets once to selected fighters so an old preview choice does not mask the new roster.
- Spectator rendering interpolates snapshots without sending combat inputs. Replays retain archived character/move catalogs, scores and snapshot timing; seeking does not accumulate effects from the previous playback position.

## Ten original rivals

- Default character selection shows Silent, Winta, Dora, Aren, Eira, Kael, Nyra, Rook, Veyra and Oryn. Aren vs Winta is the default matchup. Each has a playable kit, color/gear identity and an original backstory with connections to the others. The six new rivals reuse existing tested techniques; bespoke animations for the full roster remain future work.
- Story & connections in the kit panel introduces the missing Skyglass Heart, the northern rescue and the council’s concealed orders. Silent and Winta are blood brothers, and Silent and Dora remain married; established Silent/Winta/Dora titles, bloodlines, abilities and awakening rules remain intact. The new shared setting expands their game lore.
- Include Naruto / Boruto fighters is unchecked by default on each visit. Check it to reveal the 25 anime prototype fighters and their era/faction filters. Unchecking returns anime selections to Aren/Winta. Existing archives and explicit replay takeover can still show recorded anime characters. These fighters are classified separately, not deleted.
- The awakening drill uses Winta when the selected original has no awakening. Original kits remain customizable up to seven jutsus, two weapons and four consumables.

## Selection and post-fight comfort

- Increase roster grid height to reveal more fighters at once in desktop, portrait and landscape layouts.
- Reduce the post-fight coaching panel and typography. The tactical tip and Practice action remain visible; detailed numbers move into an expandable Match stats section.

## Compatibility and verification

- Multiplayer protocol is now 7: refresh older clients to join/watch the updated server. Combat rules remain duel-0.20.0; replay schema 1, standings, stored tournament outcomes and rewards are unchanged. No production simulation tournament is started by this release.
- Checks cover all ten kits/stories, default anime exclusion and explicit opt-in, all-mode presentation, Canvas selection, context loss/retry, original online fighters, live spectating, archived replay rendering, deterministic projectile geometry and gameplay regressions. Browser tests use software WebGL on CI; physical-phone performance remains to be measured. No frame-rate improvement is claimed.
