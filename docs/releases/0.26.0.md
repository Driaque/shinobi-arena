# Fabled Rivals v0.26.0

## Mobile comfort

- Portrait and landscape both support play. Rotating no longer pauses the match or disables controls. A small portrait tip recommends landscape for more room. Fullscreen respects the chosen orientation.
- Active touch fights use a stable viewport with no page scrolling. The play surface suppresses double-tap zoom and native gestures; menu scrolling and browser zoom outside the fight remain available. This is a responsive viewport, not a forced screen resolution.
- Narrow portrait screens use a taller control deck and a separate saved control profile. Visibility, opacity, handedness and bindings still apply; landscape layout edits remain separate.
- Native dropdowns retain OS picker and keyboard behavior. Fields use native full-surface styling; tapping their label opens the picker where the browser supports it, with normal label activation as fallback.

## Aren motion and native effects

- Training → Practice → Graphics → PixiJS · Aren preview remains opt-in. Aren still uses the selected fighter's kit. The main game and Visual Lab now share short pose crossfades, run bob/lean, jump tilt, landing settle and attack anticipation/follow-through. Atlas proportions, body scale, simulation timing and movement speed are unchanged. These are presentation improvements to the existing 16-pose atlas, not a complete newly animated rig.
- Element-colored ground fields, crouch-aware guard shields and hit rings render through the native Practice backend, with Canvas equivalents when WebGL is unavailable. Field names, weapon attacks, inventory/projectiles, status cues and damage text remain in the compatibility layer.
- Reduced motion removes new motion offsets, crossfades, trails and hit rings. Turning decorative effects off removes motes/awakening decoration; gameplay-critical fields and shields remain visible.

## Validation and next stages

- Unit checks cover bounded finite offsets for every move, state preservation, transition/reduced-motion behavior, field element/depth/expiry, portrait layout separation and fullscreen without orientation locking. Browser checks exercise portrait/landscape continuity, native picker label activation, rapid mobile attack taps, seven-jutsu loadouts, aerial combos, fields and GPU fallback/retry.
- Physical-phone frame pacing, heat and battery tests remain pending. CPU/online/replay renderer expansion and the full original competitive roster are subsequent stages; this version does not enable those modes or add characters. No speedup is claimed.
- Combat protocol 6, duel-0.20.0, rankings, rewards and persisted replay results are unchanged.
