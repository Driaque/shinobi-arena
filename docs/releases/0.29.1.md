# Fabled Rivals v0.29.1

The Save loadout button stays visible on Jutsus, Weapons and Consumables. The loadout content, including the Strategy Advisor, named builds and equipment cards, scrolls between the dialog header and footer instead of pushing Save below the screen.

Choose a slot and a card, then select Save loadout to apply your changes. Cancel closes without applying changes. Existing loadouts and combat rules are compatible and unchanged. This layout supports desktop and phone portrait and landscape screens; long lists require scrolling.
