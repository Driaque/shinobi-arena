# Fabled Rivals v0.29.1

## Discord request compatibility

- Send Discord's documented application User-Agent format on the server-side token exchange and profile lookup.
- Log only a fixed failure stage, HTTP status and timeout flag if provider verification fails. Do not log authorization codes, provider credentials, access tokens, response bodies or exception messages.
- Make the disabled-configuration test independent of credentials present during production builds.

## Controls and compatibility

- Open Profile / sign in or Arena → My profile to start Discord sign-in. Existing guest profiles, recovery codes, player IDs, ratings, history and rewards remain compatible.
- Keep the identify-only scope, state, PKCE, browser binding and one-use completion checks. Provider failures preserve the existing game profile.
- This patch corrects request headers and diagnostics. A completed real Discord authorization is still required before claiming the production sign-in flow verified. Popups are required; community-server creation, messaging and friends are not included.
