# Fabled Rivals v0.41.1

- A brief app switch, screen lock, or network interruption can pause an online fight or co-op expedition. Bring the same page back to the foreground to reconnect automatically and return to the same slot, score, and round or wave.
- Each player has 45 seconds of total reconnect time per match. Both players see a waiting message while the server holds the fight. **Leave match** still forfeits immediately while connected.
- Recovery requires the original page to remain open and the server process to retain the match. Existing clients can still join with protocol 8 and the same combat rules. Refresh the game to enable reconnect on your device. Controls are unchanged.
