# Fabled Rivals v0.37.1

## Clearer battle layout

- Controller shortcuts and cooldowns occupy a separate 64px information rail below the rendered fight, keeping fighters unobstructed while using substantially less space than the touch deck.
- Hide navigation collapses the header to a small toggle and battle actions. Show navigation restores it. The preference saves on the device and works with controller and touch layouts, including Adventures.
- Menu → Help & updates contains release notes, release history, extra project links and gameplay help. These no longer create a footer panel below the main arena.

## Controller customization

Settings → Controller bindings opens the mapping controls directly. Physical buttons use paired PlayStation/Xbox names. Customize both ordinary actions and the actions used while holding the ability modifier. Mappings save on this device and update live button prompts. Restore default controller mapping resets both layers. Existing saved mappings are retained.

Browser/controller compatibility remains unchanged. Online battles continue while settings are open. Physical controller and mobile-device testing remains separate from simulated browser coverage.
