# Fabled Rivals v0.25.0

## Aren in main-game Practice

- Choose Training, open Practice and select Graphics: PixiJS · Aren preview. The same main-game HUD, analog, keyboard/gamepad bindings, configurable control layout and equipped technique tray remain available. Aren and a matching sparring echo use the selected fighter kits; the HUD identifies those kits explicitly. No character ID, loadout or combat statistic is replaced.
- Canvas · Aren preview renders the same appearance without WebGL. Canvas · selected fighters restores the original view. Preferences save on this device. Changing graphics preserves the current fight state; the normal Start drill/free practice action still resets training as before.
- Original Aren sprites and Skyglass Terrace scenery render natively through PixiJS. Existing Canvas combat cues remain layered above them for equipped weapon attacks, projectiles, elemental fields, status effects, replacement, inventory effects, hit numbers and training range/recovery guides. This is an incremental renderer integration, not a full conversion of every effect or a finished animation set.

## Loading and fallback

- PixiJS and the original artwork load lazily only when an Aren appearance is requested in Practice. The original Canvas view stays available during loading. Dynamic bundle URLs inherit the application version.
- Missing WebGL or context loss uses the Aren Canvas view. Missing artwork, a failed module or a render error restores the original Canvas view. Retry graphics rebuilds resources and can retry a transient module-fetch failure. Leaving Practice releases the additional canvases and graphics resources; saved preferences do not enable the preview in CPU, local, online or replay views.
- Both Aren renderers share the main camera, including depth, jump zoom, shake and letterboxing. The standing sprite height follows the engine body scale. Existing reduced-motion and decorative-effects preferences apply. Physical-device performance remains to be measured; no speedup is claimed.

## Compatibility

- Existing controls, profile keys, loadout storage, combat protocol 6 and duel-0.20.0 rules remain unchanged. Aren is a Practice appearance with a mirror opponent, not a new ranked roster character. Online rankings, tournaments, rewards and replay results are unchanged.
- The standalone Visual Lab remains available for its guided showcase and local measurements. A complete original competitive roster and native PixiJS coverage for all combat effects remain future work.
