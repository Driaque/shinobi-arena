# Fabled Rivals v0.39.1

## Two-controller local selection

In Local versus, connecting a second controller gives each pad its own setup controls. Pad 1 edits P1, pad 2 edits P2. Character cards, weapons, consumables and technique loadouts are restricted to their owning controller. Each pad has its own cursor and D-pad focus; P2's cursor is purple and labeled P2. P1 controls shared menus, stage progression and starting the match.

The loadout editor remains a shared dialog: while P1 or P2 edits their equipment, only that player's pad can navigate, save or cancel it. The other pad resumes selecting when the dialog closes. Single-pad and CPU setups preserve the existing P1 selection workflow. A surviving pad 2 retains ownership of P2 when pad 1 disconnects.

## List scrolling

Pushing the left-stick cursor toward the edge of a scrollable character roster, equipment library, options list or other scrollable panel scrolls it vertically or horizontally. Scrolling requires stick input and stops on release. D-pad focus navigation also scrolls the focused choice into view. Controller input cannot scroll or select the other player's setup area.

Automated checks simulate pads; physical two-controller browser/device checks remain separate.
