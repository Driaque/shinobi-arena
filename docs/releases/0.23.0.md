# Fabled Rivals v0.23.0

## Fabled Rivals

- The game now uses Fabled Rivals on the startup splash, main header, online arena and browser title. The monogram and browser icon use FR; the page description introduces the tactical arena fighter.
- Current release pages and new GitHub Releases use the Fabled Rivals name. Older release notes retain their historical Shinobi Arena headings and remain browsable.

## Compatibility

- Controls, combat protocol 6 and duel-0.20.0 rules are unchanged. Existing profiles, settings, loadouts, tournament results and archived matches remain compatible. Browser storage keys, database schema, repository and service addresses retain their existing identifiers.
- Refresh to load the updated branding. No redirect, origin change, private profile transfer or match reset is introduced.

## Rollout limits

- This is a branding update. The current anime-inspired development roster and existing art remain in the prototype; replacement with original characters, abilities, artwork and setting is a separate release milestone.
- fabledrivals.com is the intended domain, subject to registration. It has not been purchased or connected, and this update does not change hosting or the provider-controlled cold-start screen. Personal GitHub Pages launch promotions remain removed.
