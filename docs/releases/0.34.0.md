# Fabled Rivals v0.34.0

- Menu groups Story & Co-op, Profile, Rankings, Mode and Arena. Settings groups Difficulty, Controls, Audio, Graphics and Feel. Pause and Full screen appear only during a battle; online matches cannot pause.
- Setup offers Sign in with Discord or Continue as guest. The toolbar shows the verified signed-in player name, guest profile, or an account retry state if the server cannot be reached. Identity changes refresh the indicator.
- Choose fighters and equipment first, then Continue to battle stage. Stage selection replaces the character panel inside the same setup screen. Back to characters preserves selections; Enter the arena starts the fight. Rematches and mode changes return to character selection; paused fights resume directly.
- Fixed the layered sprite/scenery canvases in Adventures so painted fighters render within the Story and four-fighter Co-op survival battlefield.

## Controls and compatibility

Menu and Settings support keyboard focus, Escape and touch. Existing combat bindings and per-device settings remain. Adventures uses the fighter style selected in the arena Graphics settings, with Canvas fallback when WebGL is unavailable.

## Limits

Discord requires a configured, reachable arena server. Guest offline play remains available without signing in. Online stage negotiation is unchanged: the first queued player's selected stage is used. Story retains authored stages; Co-op retains its shared survival stage and four selectable heroes. Online Pause remains unavailable because the server continues running.
