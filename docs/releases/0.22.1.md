# Shinobi Arena v0.22.1

## Launch cleanup

- Remove the faster-launch banner and its recovery-code message from character selection.
- Remove personal GitHub Pages play links from the splash and game footer, along with the personal canonical address and unused banner code/styles. Current launch documentation uses the existing Render address while a dedicated game-branded domain is selected.
- Keep the Shinobi Arena splash, startup retries, offline play and release history. Existing profiles and settings stay at their current browser origin; there is no redirect or data migration.

## Compatibility and limits

- Tournament podiums and stable results reading remain available. Controls, combat protocol 6, duel-0.20.0 rules, saved loadouts and archived matches are unchanged.
- This patch does not purchase a domain, move hosting or disable an existing site. The provider-controlled loading screen can still appear when opening a sleeping Render service directly. Dedicated-domain hosting remains pending selection and configuration.
