# Fabled Rivals v0.28.2

## Release reliability

- Add a Render deployment workflow that runs after successful main-branch CI, verifies the current main commit and trusted CI event, and pins the deploy hook to the verified commit.
- Wait for the public health endpoint to report healthy storage, the expected version and the exact Render commit before reporting deployment verified. Requests are bounded; failed or uncertain triggers are not automatically retried.
- Expose version and Render commit in health responses. Local development reports a null commit.

## Activation and limits

- This workflow needs the RENDER_DEPLOY_HOOK_URL GitHub repository secret. Missing configuration fails with a clear instruction; adding the workflow alone does not enable automatic deployment.
- Use this workflow as the deployment trigger and disable the native Render automatic trigger when activating it to avoid duplicate deploys.
- No gameplay, input, simulation, profiles or replay format changes. Physical-phone and real-network quality testing remain pending. Discord accounts and friends remain planned.
