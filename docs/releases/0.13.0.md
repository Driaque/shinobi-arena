# Shinobi Arena v0.13.0

## Battle inventory

- Select two equipped weapons and four consumable slots before starting a local/CPU fight or joining online matchmaking.
- Swap weapons with F. Swapping has startup/recovery and cannot cancel attacks, dashes, guard or hitstun.
- Choose a consumable with C and use it with X. P2 on a shared keyboard uses 7 / 8 / 9 for swap / choose / use.
- Each consumable slot has one charge per round. Empty slots are allowed. Ordinary tools can be duplicated; at most one Flying Raijin kunai is allowed.
- Consumables spend 8 stamina, have startup/recovery and share a 1.5-second cooldown. Interrupted or missed uses still consume the charge. New rounds and training Reset refill the selected inventory.

## Tactical consumables

- Paper Bomb: a thrown, delayed explosion with a 110-unit blast radius. Reposition, jump or guard to reduce the threat. Smoke does not stop the explosion.
- Throwing Kunai: a fast, straight, 45-damage projectile.
- Shuriken Fan: three 25-damage projectiles at different heights, useful for ranged and guard pressure.
- Poison Vial: coats the next equipped weapon attack for up to six seconds. A clean hit applies five seconds of poison; a whiff or block wastes the coating.
- Smoke Bomb: a stationary three-second cloud destroys ordinary enemy projectiles. Your own projectiles pass through. Melee attacks and bomb blasts remain effective.
- Flying Raijin Kunai: places a five-second marker when it hits or lands. Select the same slot and use it again to warp for 15 chakra. The warp grants no invulnerability and cannot escape hitstun. Smoke can stop the marking throw. This is a gameplay adaptation available to all fighters.
- Inventory counts, active weapons, smoke, bomb fuses and Raijin markers are visible during battle. Medium and higher CPU difficulty can use equipped consumables; Easy leaves room to learn.

## Customizable control visibility

- Controls now includes a checkbox for every touch control, including the analog stick and new inventory buttons.
- Hidden controls free their panel space and do not block saving other controls in that space. Keyboard bindings continue to work.
- Save persists visibility on this device; Cancel restores the previous settings. Reopen Controls to restore hidden buttons.
- Existing saved keys, opacity, placement and layouts migrate to the new settings version. New keys never overwrite custom bindings.

## Delivery and compatibility

- Every version update requires versioned release notes. After verified Pages deployment, GitHub Actions publishes a matching GitHub Release and tag automatically, once per version.
- The game links to its release notes. Builds version browser assets to avoid mixing old cached controls with a new inventory UI.
- Online loadouts, item charges, effects, swapping and warps are validated and simulated by the server. Combat rules and protocol versions changed; refresh older tabs before joining.
- Display names remain unverified labels. Online fights continue while opening Controls or switching tabs. There is no reconnect, prediction or rollback yet.
- The server fix for missing files returning 404 without crashing remains in place.
