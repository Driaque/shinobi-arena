# Fabled Rivals v0.38.1

## Left-stick menu cursor

- Left analog stick moves the cursor on setup screens and menus. Push it toward a panel edge to scroll. Cursor speed remains adjustable under Feel.
- D-pad moves focus between controls, adjusts focused sliders/selects, and repeats while held, like keyboard arrow navigation. Left-stick cursor movement no longer changes focus at the same time.
- Cross/A confirms; Circle/B goes back. Right stick no longer moves the menu cursor.
- During combat the cursor stays hidden. Left-stick fighter movement and right-stick aiming are unchanged.

Production updates now deploy only to the existing Render game at https://shinobi-arena-online.onrender.com. GitHub Pages no longer publishes automatically. Versioned GitHub release notes follow successful Render deployment.

Automated checks simulate controller input; physical device compatibility still depends on the controller, browser and operating system.
