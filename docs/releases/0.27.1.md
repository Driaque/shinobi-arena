# Fabled Rivals v0.27.1

## Living character thumbnails

- Both character-selection rosters use PixiJS to animate the existing portraits with gentle breathing, sway and independently drifting colored motes. Winta and Kael gain brief lightning accents. Hovering, keyboard focus or selecting a fighter strengthens the decorative effects. Existing radio controls and touch selection continue to work.
- A single shared WebGL renderer serves the portrait canvases, capped at 24 updates per second. Hidden cards and background tabs skip rendering. Reduced-motion preferences freeze portraits; the decorative-particles setting disables their effects. Failed art/module loading or context loss retains the static portrait.
- This animates existing portrait artwork; it does not add new character illustrations, facial rigs, blink frames or combat animations. Physical-device performance remains unmeasured.

## Compatibility

- No combat, protocol, replay or save-format changes. All originals and opt-in anime fighters retain their selection behavior.
- Verification includes the full unit suite and production build. Desktop/mobile browser coverage checks changing portrait pixels and reduced-motion stability alongside existing gameplay checks.
