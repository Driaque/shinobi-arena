# Fabled Rivals v0.36.0

- Menu and Settings panels stay inside the visible viewport, including landscape phones and browser UI changes. Long menus scroll vertically without covering off-screen actions.
- Story and Co-op inherit the same arena sizing and control-deck dimensions as versus modes. Touch battles use the available viewport with compact overlaid adventure vitals.
- Official cyan/coral emblem, wordmark and Iron Sharpens Iron banner brand the game header, favicon, loading screen and Adventures entrance.

## Controls and compatibility

Existing keyboard, touch and gamepad controls remain. Navigation supports touch scrolling and keyboard focus. The shared arena uses responsive sizing in portrait and landscape.

## Limits

Story still uses authored encounters and Co-op uses private survival rooms. Branding changes presentation only; gameplay and progression rules remain unchanged.
