# Fabled Rivals v0.28.1

## Clear character poses

- Draw one opaque painted key pose per fighter in both PixiJS and Canvas. Running and attack phases no longer crossfade unrelated silhouettes, avoiding doubled limbs, weapons and translucent bodies.
- Idle holds a stable illustration with subtle breathing instead of alternating independent paintings. Running uses its travel-based key poses; attacks still follow engine startup, active and recovery timing. Movement interpolation and foot anchors remain intact.
- Keyboard, controller, touch controls, combat rules, hitboxes, profiles and replay format are unchanged. The shared presentation applies to battles, training, spectators and replay viewing.

## Planned work

- The prioritized roadmap in docs/BACKLOG.md now includes online quality, Discord sign-in with guest-profile linking, private rooms and friend challenges, onboarding, distinct character mechanics and cosmetic mastery rewards. These are plans, not features shipped in this patch.

## Validation and limits

- Regression coverage checks opaque poses, stable idle, attack phase boundaries, jump poses, deterministic sampling and reduced-motion behavior. Gameplay browser checks remain required before release.
- This patch removes a rendering artifact; it does not add missing animation drawings, full rollback networking or Discord sign-in. Painted key poses remain discrete, and physical-phone animation quality still needs playtesting.
