# Fabled Rivals v0.40.1

## Separate cursor and scrolling controls

- Left stick moves the menu cursor. It no longer scrolls panels when reaching their edges.
- Right stick scrolls the list under the cursor: up/down for vertical lists, left/right for horizontal strips. With the cursor hidden, it scrolls the focused control's containing list. Small deflections scroll slowly, and scrolling stops on release.
- D-pad retains keyboard-style navigation and keeps focused choices visible.
- Player ownership remains enforced: each local pad scrolls and selects only its own setup area; a shared loadout dialog accepts only its owner's pad.
- These changes apply only in menus. Battle movement and right-stick ability aiming are unchanged.

Automated controller checks use simulated pads; physical browser/device compatibility remains a separate check. Production deploys only to the existing Render game.
